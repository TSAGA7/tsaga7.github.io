# MY WORLD — сайт

Собранное приложение **MY WORLD** (https://tsaga7.github.io/myworld/) и его данные.
Исходный код — в закрытом репозитории; сюда автоматически попадает только сборка:

- `myworld/` — собранный сайт;
- `collector/` — собранные скрипты сбора ленты, цен и публикации в Telegram;
- ветка `data` — лента, цены, каталоги курортов (то, что приложение показывает во вкладке «Лента»);
- ветка `tg` — что уже опубликовано в Telegram-канале.

Ветку `main` руками не править: она перезаписывается при каждой сборке.
